# Art Explorer – ITE5425 Mastery Assignment 1

**Student:** Maria Catherine Jaramillo (N01740036)

A Next.js App Router application for browsing artworks from the
Metropolitan Museum of Art public API.

## How to run
npm install
npm run dev

Open http://localhost:3000

## Main pages
- `/` – Home
- `/artwork` – Browse and search artworks (max 6 results)
- `/artwork/[id]` – Artwork details (e.g. /artwork/436535)
- `/search` – Advanced search with validation and title-only option
- `/about` – About the developer
